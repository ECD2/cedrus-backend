# Cedrus V9 — Convergence

Cedrus V9 keeps V8 Horizon Evolved as the visual source of truth: the Miami horizon, warm cream surfaces, jade/gold/slate accents, Newsreader typography, real program photography, and quiet interaction language all remain intact.

V9 advances the product structure. One explainable daily composition now connects programs, workstreams, open loops, decisions, agent runs, and confirmed commitments.

## Product flow

1. **Now** preserves the V8 horizon and images, then adds a command strip, one honest choice point, all-layer runway, and brief continuity.
2. **Day** composes all six day layers, exposes line of sight and source, and previews schedule ripples without immediately mutating the plan.
3. **Programs** keeps the visual program cards and full-bleed photography while separating plan from actual behavior and introducing universal session memory.
4. **Runs** gives machine work the same grammar as a workout: brief, prerequisites, live state, approval boundary, evidence, and finish condition.
5. **Atlas** shows outcome convergence, conflicts, and drift rather than a decorative graph.
6. **Connect** compiles Markdown into reviewable rules, lint findings, source traces, and immutable local revisions. Connector cards show truthful scope and freshness.
7. **Ask / Call / Text** share one interface and state. Twilio SMS is labeled live; voice is explicitly labeled designed but not connected.

## Truth boundaries

- This is a separate local V9 build. The V8 project is unchanged.
- V9 does not call the production backend or mutate real external services.
- Daily Brief, Twilio SMS, Resend, and Local Observer states reflect the supplied master context.
- Google Calendar, Apple Health, and Strava are shown as not connected.
- GitHub is shown as setup pending.
- Markdown revisions and the living-session start timestamp persist only in local browser storage.
- Dry runs, approvals, receipts, connection requests, and agent-run transitions are interactive local demonstrations.

## Run locally

```bash
npm run dev -- --port 4186
```

Open `http://127.0.0.1:4186/`.

For a production build:

```bash
npm run build
npm run preview
```

## Validation

```bash
npm test
```

The current build passes twelve tests, including the existing planner suite and V9 compiler tests for plan linting, rule traces, and stable source fingerprints.
